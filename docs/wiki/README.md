## Как пользоваться вики

Файлы лежат в каталоге `docs/wiki/` в том же репозитории, что и код. Их можно открывать в IDE или на GitHub (навигация по ссылкам в Markdown). При желании содержимое можно перенести в [вики GitHub](https://docs.github.com/en/communities/documenting-your-project-with-wikis/about-wikis) вручную.
