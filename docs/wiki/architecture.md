# Архитектура

## Приложения

| Приложение | Назначение |
|------------|------------|
| `config` | Настройки, `urls.py`, валидация изображений, список запрещённых слов для товаров |
| `catalog` | Главная, каталог, категории, карточка товара, контакты, CRUD товаров |
| `blog` | Список и детали постов, CRUD записей блога |
| `users` | Модель `User`, регистрация, вход, выход, профиль |

## Маршруты верхнего уровня (`config/urls.py`)

- `/admin/` — админка Django  
- `/accounts/` — включение `users.urls` (регистрация, вход, выход, профиль)  
- `` (пустой префикс) — `catalog.urls` (главная, товары, каталог, категории, контакты)  
- `/blogs/` — `blog.urls`  

Карточка товара: **`/product/<id>/`**, не под префиксом `catalog/`.

## Пользователь и авторизация

- `AUTH_USER_MODEL = users.User`, вход по полю **email** (`USERNAME_FIELD`).  
- Защита страниц: `LoginRequiredMixin` на карточке товара, CRUD товара, CRUD блога (кроме публичного списка и просмотра статьи), профиле.  
- `LOGIN_URL` → `users:login`; редиректы после входа/выхода — на главную каталога.

## Медиа и статика

- Загрузки: `MEDIA_ROOT` (аватары, фото товаров, превью блога).  
- В `DEBUG=True` медиа отдаёт Django (`static()` в `urls`).

## Логирование

- `catalog/views.py` пишет информацию о последних товарах в `logs/catalog_views.log` (каталог `logs/` в `.gitignore`).
