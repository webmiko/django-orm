# django-orm

Учебный Django-проект: интернет-витрина товаров с каталогом, блогом, обратной связью и разграничением прав доступа. Кеширование через Redis.

## Стек

- Python 3.10+, Django 5.x, Poetry
- PostgreSQL / SQLite
- Redis (кеширование)
- Pillow (изображения)
- Bootstrap 5
- pytest, Ruff

## Требования

- Python 3.10+
- [Poetry](https://python-poetry.org/)
- PostgreSQL (рекомендуется) или SQLite
- Redis (опционально, для кеширования)

## Быстрый старт

```bash
# 1. Установка зависимостей
poetry install

# 2. Настройка окружения
cp .env.example .env
# Отредактируйте .env: DB_NAME, DB_USER, DB_PASSWORD и др.

# 3. Миграции
poetry run python manage.py migrate

# 4. Создание групп и прав
poetry run python manage.py setup_catalog_groups

# 5. Суперпользователь (для админки)
poetry run python manage.py createsuperuser

# 6. (Опционально) Демо-данные для проверки прав
poetry run python manage.py seed_demo_users

# 7. Запуск сервера
poetry run python manage.py runserver 8080
```

Сайт: http://127.0.0.1:8080/ | Админка: http://127.0.0.1:8080/admin/

```

├── templates/          # Общие шаблоны
├── docs/               # Планы разработки, вики
└── pyproject.toml      # Зависимости и настройки линтеров
```

## Разграничение прав

| Роль | Каталог | Блог |
|------|---------|------|
| **Анонимный** | Просмотр опубликованных товаров и категорий | Просмотр опубликованных статей |
| **Авторизованный** | Создание товара (становится владельцем) | — |
| **Владелец товара** | Редактирование и удаление своих товаров | — |
| **Модератор продуктов** | Удаление любого товара, публикация/снятие | — |
| **Контент-менеджер** | — | Создание, редактирование, удаление записей |

Группы создаются командой `setup_catalog_groups`.

### Демо-пользователи

Создаются командой `seed_demo_users`:

| Логин | Роль | Пароль |
|-------|------|--------|
| `demo_owner` | Владелец товаров | `DemoPass1!` |
| `demo_moderator` | Модератор продуктов | `DemoPass1!` |
| `demo_content` | Контент-менеджер | `DemoPass1!` |
| `demo_plain` | Обычный пользователь | `DemoPass1!` |

## Кеширование (Redis)

При `CACHE_ENABLED=True` в `.env` подключается Redis:

```
CACHE_ENABLED=True
REDIS_URL=redis://127.0.0.1:6379/1
```

Что кешируется:
- **Карточка товара** — `cache_page`, 15 мин.
- **Список товаров в категории** — низкоуровневое кеширование (`cache.get` / `cache.set`), 15 мин.

При `CACHE_ENABLED=False` приложение работает без Redis.

## Основные URL

| URL | Описание | Доступ |
|-----|----------|--------|
| `/` | Главная (последние товары) | Все |
| `/catalog/` | Каталог с фильтрами | Все |
| `/category/<id>/` | Товары категории | Все |
| `/product/<id>/` | Карточка товара | Опубликованные — все; черновики — владелец/модератор |
| `/product/manage/` | Управление товарами | Авторизованные (свои / все для модератора) |
| `/product/add/` | Создание товара | Авторизованные |
| `/product/<id>/edit/` | Редактирование | Владелец |
| `/product/<id>/delete/` | Удаление | Владелец или модератор |
| `/product/<id>/publish/` | Публикация (POST) | Модератор |
| `/blogs/` | Список статей | Все |
| `/blogs/<id>/` | Статья | Опубликованные — все |
| `/blogs/create/` | Создание записи | Контент-менеджер |
| `/contacts/` | Обратная связь | Все |
| `/accounts/register/` | Регистрация | Гости |
| `/accounts/login/` | Вход по email | Гости |
| `/accounts/profile/` | Профиль | Авторизованные |

## База данных

**PostgreSQL** (рекомендуется): задайте `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` в `.env`.

**SQLite** (запасной вариант): удалите или закомментируйте `DB_NAME` в `.env` — используется `db.sqlite3`.
